Public CLI and infrastructure tools packaged as RPMs for Fedora 43+ (x86_64), built and delivered through Packit + Copr so `dnf upgrade` tracks new upstream versions. Currently ships: gitea-cli (gt, the official Gitea command-line client and successor of tea), tea (the Gitea/Forgejo command-line client, archived upstream), actionlint (static checker for GitHub Actions workflow files) and Anchore's software supply-chain trio — syft (SBOM generator), grype (vulnerability scanner) and grant (license checker).
